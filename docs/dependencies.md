# Dependency register

Every runtime entry from the root `composer.json` `require` object is listed
below; `require-dev` is not. The register is reviewed at every release and in
every PR that changes `require`.

| Dependency                    | Version constraint | Why this minimum                                                                                                                        | What we use                                                                                                                                                                                              | What we replace or extend and why                                                                                                                                                          | Maintainer                | License | Known risk                                                                                                                                                    | Exit plan within this package                                                                                        |

| `php`                         | `^8.3`             | Floor set at the scaffold (#1); the fleet standard for new packages. Laravel 12/13 would allow lower, so the floor is this package's own choice. | Language runtime: readonly classes, enums, `str_ends_with`, first-class callables across `src/`.                                                                                                     | Nothing to replace; platform requirement.                                                                                                                                                 | PHP Group                 | PHP-3.01 | None known.                                                                                                                                                     | Not replaceable; the floor is raised deliberately per release.                                                      |
